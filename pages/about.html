O projeto

O PC Building é site informacional, que conta com metodologia de aprendizagem por meio de um jogo educativo desenvolvido com o objetivo de ensinar, de forma simples e intuitiva, o processo de montagem de computadores.

Nosso ambiente virtual combina tutoriais explicativos sobre compatibilidade entre peças com uma mecânica de jogo de Drag and Drop (arrastar e soltar), na qual o usuário posiciona os componentes em uma área de trabalho e testa, na prática, os conhecimentos adquiridos.

Nota: O projeto foi desenvolvido como atividade acadêmica de faculdade, com o propósito de criar uma plataforma que auxilie usuários no processo de montagem de computadores, apresentando informações sobre componentes, compatibilidade entre peças e possíveis configurações de PC.

A equipe

Tecnologias Utilizadas

Linguagens

  • HTML5 — linguagem de marcação usada para definir a estrutura das páginas;
  • CSS — folhas de estilo utilizadas para estilizar as páginas HTML;
  • JavaScript — linguagem dinâmica e fracamente tipada, responsável pela lógica do jogo e pela mecânica de Drag and Drop.

Ferramentas

  • Git e GitHub — versionamento e colaboração no código;
  • Trello (Kanban) — organização das tarefas da equipe e wireframes;
  • Wireframes — base visual para o desenvolvimento das páginas do site.
Nota: O JavaScript atua no comportamento do site como um todo, sendo a linguagem responsável por toda a lógica de funcionamento do jogo, incluindo a verificação de compatibilidade entre os componentes selecionados pelo usuário.
